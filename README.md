# Лабораторная работа №5

## URL Shortener

---

# Постановка задачи

Необходимо реализовать упрощённый сервис сокращения ссылок.

Система должна обеспечивать хранение длинных URL-адресов и их связь с короткими кодами.

Пример:

```text
a1b2 -> https://example.com/articles/python-basics
```

### Обязательная часть

Реализовать следующие возможности:

* добавление новой ссылки;
* получение длинной ссылки по короткому коду;
* проверка существования короткого кода;
* вывод всех сохранённых ссылок.

### Вариативная часть №9

Реализовать возможность изменения длинной ссылки для существующего короткого кода.

---

# Структура программы

## Класс UrlShortener

Основная логика программы реализована в классе `UrlShortener`.

Для хранения данных используется контейнер:

```cpp
unordered_map<string, string> links;
```

где:

* ключ — короткий код ссылки;
* значение — полный URL-адрес.

---

# Реализованные методы

| Метод            | Назначение                                 |
| ---------------- | ------------------------------------------ |
| `addLink()`      | Добавление новой ссылки                    |
| `getLink()`      | Получение длинной ссылки по короткому коду |
| `checkCode()`    | Проверка существования короткого кода      |
| `showAllLinks()` | Вывод всех сохранённых ссылок              |
| `updateLink()`   | Изменение длинной ссылки                   |

# Пример работы программы

Добавление новой ссылки:

```text
===== URL Shortener =====

1. Add link
2. Get long URL
3. Check short code
4. Show all links
5. Update long URL
0. Exit

Enter your choice: 1

Enter short code: abc1
Enter long URL: https://google.com

Link added successfully.
```

Получение ссылки по короткому коду:

```text
Enter your choice: 2

Enter short code: abc1

Long URL: https://google.com
```

Изменение длинной ссылки:

```text
Enter your choice: 5

Enter short code: abc1

Enter new long URL: https://github.com

Link updated successfully.
```

Вывод всех ссылок:

```text
All shortened links:

abc1 -> https://github.com
x7k9 -> https://youtube.com
```
